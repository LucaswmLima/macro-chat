# Macro Chat

A simple tool designed to complement the **Kefka FFXIV Simulator** by providing chat macros that can be used alongside the simulator.

The simulator itself doesn't provide a convenient way to use chat macros, so Macro Chat was created to make training easier by allowing you to quickly send predefined messages and commands while practicing.

## Download

Download the latest version from the [Releases](https://github.com/LucaswmLima/macro-chat/releases) page.

## Usage

1. Open Macro Chat.
2. Configure your desired macros.
3. Run the Kefka simulator.
4. Use Macro Chat alongside the simulator during training.

The goal is simply to make training with chat macros more convenient.
